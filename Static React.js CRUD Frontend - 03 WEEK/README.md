# 🚀 React Static CRUD Application

A CRUD application built with React 19 and Tailwind CSS. This project demonstrates how to manage frontend efficiently without a Backend and Persistent State, featuring a modern UI and optimized build tooling via Vite.

---

## ✨ Features

Create: Add new records via form.

Read: View data in a table layout.

Update: Inline editing of existing entries.

Delete: Remove entries with immediate UI response.

---

## 🛠️ Tech Stack

Framework: React

Build Tool: Vite

Styling: Tailwind CSS
